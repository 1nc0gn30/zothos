# 🜂 ZOTH APPIMAGES
> Sovereign Standalone Application & AppImage Registry for ZOTHOS Linux.

This repository maintains verified AppImages, binaries, and desktop launchers for ZOTHOS. When a user runs ZOTHOS, they can install any AppImage on demand with automatic desktop shortcut integration.

---

## ⚡ Available Applications

| App ID | Name | Category | Description |
|---|---|---|---|

---

## 🚀 Usage

```bash
# List available AppImages
zoth appimage list

# Install an AppImage and pin to Desktop
zoth appimage install obsidian
zoth appimage install burpsuite
zoth appimage install caido

# Remove an AppImage
zoth appimage remove obsidian
```
