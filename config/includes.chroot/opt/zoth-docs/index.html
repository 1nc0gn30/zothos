Architecture & The Hows

How ZothOS is structured under the hood and how key systems interact.

Root Filesystem & Hybrid Squashfs

ZothOS is delivered as a hybrid ISO using a high-density XZ compressed SquashFS root image. When booted live, an overlayfs layer mounts an in-memory copy-on-write workspace that leaves host disks untouched unless explicitly mounted.

zoth-doctor

The Tool Nexus Dispatcher

Tool Nexus orchestrates 10 distinct domains (Core, AI Runtimes, Agents, Compilers, Media, Sec, Web3, Vision, Net, PKM). Rather than broken wrappers, it resolves authentic vendor packages, user binaries, and environment variables dynamically.

zoth-tool-nexus

Zoth Desk & Telemetry Bus

Zoth Desk combines an Electron native frontend with an asynchronous Python backend and direct Node.js system metric fallbacks. It monitors CPU loads, RAM usage, storage, network traffic, listening ports, and resident LLMs with zero cloud dependencies.

Philosophy & The Whys

The deliberate architectural decisions behind ZothOS.

Why Debian Stable as the Foundation?

Rolling distributions (Kali, Arch) suffer from kernel breakage, library deprecations, and compositing crashes during live operations. ZothOS pins Debian 13 Bookworm/Trixie for bulletproof kernel stability, then surgically imports Kali and Parrot repositories through pinned apt policies.

Why Local Agents over Cloud Monoliths?

Cloud AI is metered, surveilled, and subject to arbitrary alignment changes. By pairing Nous Research Hermes, OpenAI Codex CLI, and local Ollama daemons directly with native Linux tooling, the developer retains full ownership over reasoning and output.

The Do's & Don'ts

Operational security guidelines for working in high-stakes environments.

DO: Use Reality Switcher to toggle NullAI Ghostmode before running network reconnaissance on untrusted targets.
DO: Verify your PATH and compiler status using zoth-tool-nexus before attempting complex Web3 or Rust smart contract builds.
DO: Use zoth-netkill instantly if suspicious outbound telemetry or unexpected socket traffic is observed.
DON'T: Run arbitrary pipe-to-bash (curl | bash) scripts without inspecting their sources and checksums.
DON'T: Store unencrypted private keys, seed phrases, or sensitive API secrets in live root without persistence configured.
DON'T: Commit git repositories from live workspaces with sensitive tokens in command history.
