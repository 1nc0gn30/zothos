# Agent Config

## Fields

- Label: agent name shown on the canvas and in logs
- Role: `leaf` or `orchestrator`
- Provider / Model: provider and model used for this agent
- System Instructions: prompt/context for the agent
- Tools: tools the agent can use
- Skills: skills loaded for the agent
- Pet / Mascot: spirit-animal mascot for the agent
- Loop Control: run once, loop, retry, max loops
- Timeout: seconds before stopping

## Editing

- Click an agent node to open the sidebar
- Use the sidebar form to edit agent config
- Delete an agent from the sidebar footer

## Running

- Click `Run Flow` in the toolbar
- Agents execute top-down from source to target nodes
