# Brand Identity

## Logos

| Variant | File | Usage |
|---|---|---|
| Navbar Light | `public/assets/brand/elite-connect-navbar-logo.png` | Default nav |
| Navbar Dark | `public/assets/brand/elite-connect-navebar-logo-dark-mode.png` | Dark mode nav |
| Logo Light | `public/assets/brand/elite-connect-logo.png` | Footer watermark, light mode |
| Logo Dark | `public/assets/brand/elite-connect-logo-dark-mode.png` | Footer watermark, dark mode |

Logo swap is handled by JavaScript `MutationObserver` watching `html.dark` class.

## Color System

See [[02-Design-System/Color-Palette\|Color Palette]] for full details.

Key colors:
- **Brand Blue:** `#76A8CD` — links, accents, hover states
- **Amber:** `#f59e0b` → `#d97706` — CTAs, primary buttons
- **Ink:** `#0f172a` (light) / `#f0f4f8` (dark) — body text
- **Paper:** `#f0f4f8` (light) / `#0a0e14` (dark) — page background

## Typography

- **Display:** JetBrains Mono — eyebrow labels, buttons, badges
- **Body:** DM Sans — headings, paragraphs, UI text

## Tone of Voice

- Direct, professional, local
- No fluff or generic SaaS language
- Specific to Hampton Roads / Virginia Beach
- "Built clean" is the core brand phrase
